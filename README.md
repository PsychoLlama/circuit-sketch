Electrical circuit editor and simulator running in your browser. [View it live](https://circuit-sketch.gibson.workers.dev/).

> This is vibe coded abandonware.

## Purpose

A few goals:

1. Evaluate OpenAI's Astra model on a toy project.
2. Work more with Codex CLI, building up its capabilities to match my Claude config.
3. Use this as an excuse to learn a little more electrical theory.
